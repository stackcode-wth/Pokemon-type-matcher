# ⚡ Pokémon Type Quiz

A fun, interactive web application to test your knowledge of Pokémon types! Built with vanilla JavaScript, HTML, and CSS.

# 🚀 Features
* **Interactive Gameplay:** Guess the correct type for various Pokémon.
* **Score Tracking:** Keep track of your score as you play.
* **Sleek UI/UX:** Designed with a modern dark theme inspired by modern gaming dashboards, featuring responsive card layouts and smooth transitions.
* **Dynamic Views:** Seamless transition between the welcome homepage and the live quiz screen.


# 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Styling, Flexbox, and custom layouts
* **JavaScript (ES6+)** - Game logic, DOM manipulation, and view toggling
